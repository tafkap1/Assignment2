# CSC 461/592 – Assignment 2 Unity
VR Museum
## Scene 1 – VR Museum
This is a museum that supports a VR headset. This museum is about the history of the PlayStation console and features each mainline release (PS1 - PS5). 
<img width="2537" height="1315" alt="a2 - 1" src="https://github.com/user-attachments/assets/f5965a5a-c00d-4d56-94be-638221d99ab2" />

Each exhibit features a model of the console that it is describing, a pillar to stand on, a spotlight to enhance each exhibit, a logo for each model, and a teleport hotspot for locomotion
<img width="1205" height="680" alt="a2 - 2" src="https://github.com/user-attachments/assets/5d390b69-86e3-4074-92d6-d5196b4b22db" />
<img width="2367" height="1263" alt="a2 - 3" src="https://github.com/user-attachments/assets/9491d41b-5585-4cf6-abc3-96d4cab43907" />

There is also a directional light with a dark grey color to give the room a shadowy atmosphere. This makes the exhibits pop out.
<img width="1215" height="655" alt="a2 -3 " src="https://github.com/user-attachments/assets/42ce8eae-2977-4d26-8d48-914b1a639cb8" />

Each exhibit is also equipped with a panel describing the model and its history. I implemented a trigger zone on each exhibit that automatically shows the text and also plays the sound of each console's startup to truly immerse the viewer.
